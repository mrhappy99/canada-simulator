# Findings: how indiansimulator.com is built (studied, not copied)
- The public site is a Next.js app (marketing page + i18n). The game runtime loads in lazy webpack chunks: React Three Fiber (`@react-three/fiber`) on top of Three.js `WebGLRenderer`, with ACES Filmic tone mapping, PCFSoft shadows, `HemisphereLight` + directional sun, `FogExp2`, and an `EffectComposer`/postprocessing pass (bloom).
- Assets are GLTF models with DRACO/KTX2 compression. The character uses a capsule-style controller with KeyV view toggle, KeyE interact, ShiftLeft sprint and pointer-lock / drag look. Audio runs through WebAudio. A zustand-style store tracks completed scenes in localStorage, and server-side entitlement (`/api/entitlement`) gates paid levels.
- Canada Simulator 3D borrows only the *patterns*: one level meter, short levels, results screen and Try Again, a hub grid with Story mode, and contextual E prompts. Its code (vanilla Three.js r170, no bundler), procedural primitive models, canvas-painted textures, synthesized audio and all text are original.
